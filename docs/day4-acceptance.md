## 进阶实现（超出基础要求）

- **连线状态可视化**：不仅节点会变色，当流程从一个节点流转到下一个节点时，连线会变成蓝色并播放动画；如果是“打回重写”，连线会变成橙色，明确指示回退逻辑。
- **状态图例**：在侧边栏加入了图例说明，让非技术用户也能看懂图表（蓝色=运行中，绿色=完成，橙色线=重写）。

## 踩坑与排错记录

1. **React Hook 渲染死循环**：在 `useCallback` 中错误地引入了 `setNodes` 依赖，导致组件无限重渲染（Too many re-renders），进而导致 WebSocket 连接崩溃。解决：移除了对 React 稳定函数的依赖，或直接使用普通函数。
2. **WebSocket 提前断开**：后端在推送节点状态时，误将结束信号（`type: "done"`）用在了中间节点上，导致前端提前关闭了连接。解决：严格区分 `node_start`、`node_done` 和最终的 `done`。
3. **父容器高度问题**：React Flow 要求父容器必须有明确的宽高，且 Tailwind 的 `h-screen` 需要确保生效，否则会导致白屏。

## 验收结论

**Day 4 四项验收标准全部通过。** 工作流已从纯文本日志升级为动态交互的节点拓扑图，UI 表现力显著提升。
